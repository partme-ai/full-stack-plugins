# SpecGuard（需求规格防护）

让需求、验收、设计、任务与测试义务保持可追踪。

## 使用顺序

1. 识别目标仓库、事实源和当前可用工具。
2. 有真实 CLI 时执行并保留证据。
3. 工具未实现或不可用时报告 DESIGN_ONLY / NOT_RUN，不报 PASS。
4. 输出交给 GuardEngine、FlowGuard 或独立 CI。

## 边界

- 不替代其他专业 Guard。
- 不伪造门禁通过。
- 语义不确定时交人工复核。
